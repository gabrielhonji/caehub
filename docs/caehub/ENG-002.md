# ENG-002 — colaboração e integração Git

O CAEHUB possui um único repositório remoto como fonte de colaboração.

- Um incremento deve partir de uma base que já contenha suas dependências.
- Cada agente valida seus critérios de aceite, cria um commit descritivo e envia sua branch ao concluir o incremento.
- Trabalho paralelo usa branches ou worktrees apropriados; não compartilhe uma árvore de trabalho com alterações não commitadas.
- A integração em `main` precisa ser verificada antes de ser considerada pronta.
- Não reescreva histórico compartilhado nem use force push para integrar incrementos.

Quando mais de um incremento estiver pronto, integre apenas a partir das referências já publicadas, preservando os commits existentes e respeitando a ordem de dependências.

## Entrega autorizada e publicação

O pedido Agente 05 autoriza commit, push, integração em `main` e deploy pelos
canais oficiais depois do aceite e gate completo. Respeite proteções/revisões,
preserve mudanças alheias e nunca use force push. Autorização não concede
alterações de infraestrutura, Keycloak ou outros projetos. Consulte o runbook
global de produção; comandos Docker e canais SSH rodam fora do sandbox com
`require_escalated`. O relatório distingue implementação, validação visual,
testes/gate, commit, push, integração e deploy com verificação publicada.
Falha externa deixa somente as etapas dependentes bloqueadas.
